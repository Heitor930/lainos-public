# ‡ LainOS — pacotes que vêm na ISO.
#
# A ISO é enxuta de propósito: jogos, servidor, ferramentas de desenvolvimento e
# o arsenal de segurança entram depois, pelo app de boas-vindas (lain-bundle).
#
# Como o build.sh lê este arquivo:
#   nome          obrigatório: se não existir nos repositórios, o build para
#   ?nome         opcional: se não existir, é pulado com um aviso
#   a|b           usa o primeiro que existir (útil quando um pacote muda de nome)
#   ?a|b          a mesma coisa, mas opcional
# Só pacotes dos repositórios oficiais do Arch (core, extra). Nada do AUR.
